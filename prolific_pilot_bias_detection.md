## P1 · `heart_interview_20260519T113427Z_d191c826.json`

- **Prolific ID:** 6980eafaa497e7e20bf0b72f  
- **관계:** friend  
- **갈등:** college trip, 친구가 싫어하는 제3자 동행 → ultimatum → “we wont talk and bye”

| Bias | 판정 | 근거 (participant) |
|------|------|-------------------|
| Hostile attribution bias | 부분 | 분노·“wanted to actually slap him”; 상대가 이해하지 않음. 적대 **의도** 단정은 약함. |
| Correspondence bias / Fundamental attribution error | 탐지됨 | “maybe he was more attached to that person”; 친구 **성향·선택**으로 설명. |
| Actor–observer bias | 부분 | 본인: 불편한 사람 때문에 선 긋기 / 상대: 애착·다른 관점. 비대칭은 있으나 짧음. |
| Mind reading / arbitrary interpretation | 탐지됨 | “he didnt see it that way”; “maybe he was more attached…” |
| Egocentric bias / perspective anchoring | 탐지됨 | “he would have said ok i understand you i wont bring him along”; ideal = “if he said ok”. |
| Illusion of transparency | 부분 | 간단한 ok·선택이 통할 것 ↔ 상대는 다르게 봄. |
| Naïve Realism | 부분 | 친한 친구면 당연히 이해 — 상대와 **각도가 다름** 인식은 있음. |
| Confirmation bias | 부분 | “he is not my good friend at all” — 제3자에 대한 기존 틀. |
| False consensus effect | 탐지됨 | close friend면 **같은 규범**(이해·포기) 공유할 것 기대. |
| Positivity effect (aging) | 없음 | — |
| Belief Bias | 없음 | — |
| Stereotyping | 없음 | — |
| Availability Bias | 부분 | 싫은 사람 한 명이 갈등 **시작점**. |
| Spotlight Effect | 없음 | — |
| Ambiguity Aversion | 부분 | 상대 반응 abrupt; 추측으로 메움 (“maybe attached”). |
